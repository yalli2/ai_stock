# AI 주식 트레이딩 연습실

하루 목표수익률이 요구하는 승률·손익비를 계산하고, AI와 함께 매매 의사결정을 점검·자동화하는 과정을 단계별로 익히는 초보자용 인터랙티브 가이드입니다.

- 목표수익률 현실 계산기 / 몬테카를로 시뮬레이터
- 손절·비중 계산기
- AI-랩(WRAP) 4단계 질문 생성기, 7개 재무 지표
- AI 자동화 3단계 (알림 → 노코드 백테스트 → 에이전트 AI)
- 매일 루틴 체크리스트와 투자 일지 (브라우저 저장, CSV 내보내기)

참고한 책: 머신러너, 『할 수 있다! AI 주식 투자』. 책의 체계를 요약·재구성했으며 문장은 새로 썼습니다.

학습용 자료이며 투자 권유가 아닙니다. 수익을 보장하지 않습니다.
